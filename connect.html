Connect or reconnect

Connecting AR requires your explicit authorization through Intuit. This page provides instructions only: it does not start OAuth, collect credentials, or receive authorization callbacks.

Setup status

AR is under development. Production credentials and the local HTTPS callback must be configured and verified by the Operator before the intended desktop authorization flow can be used. There is no public self-service connection flow yet.

Authorization workflow

  1. Contact the Operator through your existing business contact channel to confirm that your local integration setup is ready.
  2. On the computer running the configured local tool, start its authorization flow. For the research CLI, the command is qbo-research auth login; run it only after credentials and a supported redirect flow are configured.
  3. Open the Intuit authorization link supplied by that tool, sign in on Intuit's website, and select the intended company. Authorize only an account you are permitted to access.
  4. Complete the configured callback flow and return to the local tool to verify the company and connection status. If consent is denied or the flow fails, no success should be assumed.

To reconnect after access expires or is revoked, repeat the configured local authorization flow. Do not use an old authorization link.

Keep credentials private

Do not enter your QuickBooks password on this website or post secrets, tokens, or callback URLs in chat or public issues. An authorization callback URL can contain a sensitive, temporary code.
